건설중인자산(CIP) 감가상각 개시시점 손익 영향 시뮬레이터

삼성전자·SK하이닉스 사업보고서/감사보고서(DART)에서 추출한 데이터를 바탕으로, 핵심감사사항(KAM)으로 지적된 "건설중인자산 → 유형자산 대체(가동개시) 시점 판단"이 몇 개월 앞당겨지거나 늦춰졌을 때 당해년도 손익에 미치는 영향을 정액법 가정 하에 계산합니다.

이 시뮬레이션이 계산하는 것: 가동개시 판단이 실제보다 N개월 빨랐거나 늦었다면 감가상각비·영업이익·당기순이익이 얼마나 달라졌을지에 대한 근사치입니다. 계산하지 않는 것: 실제 판단이 틀렸다는 의미가 아닙니다 — 감사인은 감사절차를 통해 적정의견을 냈습니다. 판단 하나가 재무제표에 미치는 영향의 크기를 체감하기 위한 학습 도구입니다.

LG디스플레이는 왜 이 KAM이 아닌가

CIP(건설중인자산)를 보유한 다른 기업에서도 이 KAM이 나타나는지, LG디스플레이 3개년 감사보고서로 검증했습니다.

회계연도감사인핵심감사사항(KAM)
FY2023 (제39기)삼정회계법인① 디스플레이 CGU 손상검사 ② 이연법인세자산 실현가능성 평가
FY2024 (제40기)삼일회계법인① CGU 손상평가 ② 이연법인세자산 실현가능성 평가
FY2025 (제41기)삼일회계법인① 영업권 배분 CGU 손상검사
→ "CIP 보유"는 필요조건일 뿐, 대규모 신규 팹 증설이 진행 중일 때만 이 KAM이 나타난다.
3개년 모두 "건설중인자산 → 유형자산 대체(가동개시) 시점 판단"은 KAM으로 다뤄지지 않았습니다. LG디스플레이는 같은 기간 광저우 법인 매각 등 사업 축소·구조조정 국면에 있어, 손상·이연법인세 이슈가 감사인 입장에서 더 유의적이었던 것으로 보입니다 — 삼성전자·SK하이닉스는 반대로 신규 팹을 계속 증설하는 성장 국면입니다.

감사절차 원문 ↔ 정량적 손익영향 매핑

SK하이닉스 FY2025(연결·별도)와 삼성전자 FY2025(연결)원문 미확보는 KAM이 disclosed된 사실은 사업보고서 요약표로 확인되지만, "감사에서 다루어진 방법" 원문 단락은 확보한 자료에서 찾지 못해 표에 올리지 않았습니다.

DART Open API 자동 대사(Reconciliation)

지금까지 손으로 옮겨 적은 숫자를 DART Open API로 독립적으로 재조회해 재계산(recalculation)합니다 — 감사절차 중 하나를 코드로 구현한 것입니다. (dart_fetcher.py)

✅ 자동화한 것

  • corp_code 자동 조회 (회사명 → 고유코드)
  • 재무제표(자산총계 · 유형자산) 자동 조회
  • total_assets.csv 수기입력값과 자동 대사 → 일치 여부 출력

⚠ 자동화하지 않은(못한) 것

  • KAM 본문(감사절차 텍스트)은 구조화 API가 없어 자동추출 불가 – 원문은 여전히 사람이 읽고 판단
  • 이 환경엔 실제 Python이 없어(Store 실행 별칭뿐) 직접 실행 검증은 하지 못함 – 사용자 환경에서 실행 확인 필요
# PowerShell: $env:DART_API_KEY = "..." export DART_API_KEY=... python dart_fetcher.py
